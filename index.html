Cara kerja

Settingan disimpan ke JSONBin.io — layanan cloud gratis khusus menyimpan JSON dari browser. Tidak ada CORS, bisa diakses dari browser dan device manapun.

Step 1 — API Key

Daftar gratis di jsonbin.io → masuk ke dashboard → API Keys → copy Secret Key → paste di sini.
Key tersimpan hanya di browser ini, tidak dikirim ke mana pun selain JSONBin.

Step 2 — Bin ID

Klik "Buat Baru" untuk auto-create Bin baru (butuh API Key di Step 1). Atau isi manual Bin ID yang sudah ada.
